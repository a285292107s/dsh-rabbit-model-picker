# 墨色设计语言（本插件的重制规范）

> 这份文件是 2026-10-17「整体 UI 焕新」轮**最终**的单一事实源。第一版是「终末地 HUD」，
> 被用户否掉（「我们不是游戏 HUD」「软黄色背景和 DSH 默认色差异过大」）；现行方向是
> **单色墨色 + 宿主蓝、去掉 HUD 语汇、局部墨晕 + 细微噪点**。实现记录在 `DESIGN.md` §5.38，
> 取舍记录在 [ADR 0005](adr/0005-ink-language.md)。

## 0. 修正记录（为什么不是 HUD）

| 第一版（已废弃） | 用户否决的理由 | 现行做法 |
|---|---|---|
| 信号黄（柠檬黄）作强调 | 软黄色调与 DSH 默认色差异过大 | **移除黄色**；唯一彩色强调 = 宿主自己的信息蓝（`--dsw-alias-state-business-primary`） |
| 英文字段码（`MODEL LINK` / `PROVIDER MANIFEST`…） | 这是软件，不是游戏 HUD | 字段码全部删除，`FIELD_CODES` 退役；分区只用中文标题 |
| 大号显示数字、`[ 13 ]` 括号计数 | HUD 语汇 | 删除；计数仍由句子与普通数字陈述 |
| 14px 切角 + 45° 短线、顶部扫光 | HUD 语汇 | 删除；负空间与 1px 线承担结构 |
| 页首 2px 信号顶条、行内黄左条 | HUD 语汇/黄调 | 删黄色条；选中态用**宿主蓝 2px 条**（图形），其余用填充与线 |
| 「技术拉丁」大写宽体 | 太像仪表盘 | 保留内嵌 Archivo（用户上一轮明确要过），但**只用常规字重/字距**，不再用 `wdth` 125 与大写字段码 |

保留下来的是上一版真正有价值的部分：**结构**（1px 细线、字号阶梯、两位序号、对齐）、
**双主题同构**、**内嵌字体**、**门逐条测量**。

## 1. 命题句

> 界面是一张**墨与纸**：底色有极淡的墨晕与纸纹，字是墨，线是淡墨；唯一会「跳出来」的
> 是宿主自己的蓝色——它只出现在「你正在这里 / 点这里」的地方。秩序来自线与字，不来自色块。

## 2. 令牌层（`--zmd-*`）

**规则**：本插件自己的取值一律落进 `designSystem.ts` 令牌块（`:root` 亮色默认，
`body[data-ds-dark-theme]` 暗色覆盖），样式表只允许 `var(--zmd-*)` 与宿主 `var(--dsw-*)`。
强调色与错误色**直接指向宿主令牌**，不再引入第二套色板。

### 2.1 中性色（纸 / 墨 / 线）

| 角色 | 令牌 | 亮色 | 暗色 | 允许画字 |
|---|---|---|---|---|
| 面板 | `--zmd-panel` | `#f6f6f4` | `#1a1a1a` | — |
| 沉底 / 井 | `--zmd-panel-deep` | `#ededeb` | `#121212` | — |
| 悬停 / 选中填充 | `--zmd-hover` | `#e7e7e4` | `#242424` | — |
| 细线（结构） | `--zmd-line` | `#d8d8d4` | `#333330` | — |
| 重线（边界） | `--zmd-line-strong` | `#b4b4ae` | `#5a5a56` | — |
| 控件边（表单） | `--zmd-line-control` | `#82827c` | `#85857e` | — |
| 正文墨 | `--zmd-ink` | `#141414` | `#f1f1ee` | 是 |
| 次级墨 | `--zmd-ink-secondary` | `#4c4c48` | `#b6b6b1` | 是 |
| 弱墨 | `--zmd-ink-mute` | `#66665f` | `#8b8b86` | 是（10px 序号两主题 ≥4.5） |

### 2.2 墨晕与纸纹

| 令牌 | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--zmd-wash-top` | `#fbfbfa` | `#222222` | 墨晕亮端（面板左上） |
| `--zmd-wash-bottom` | `#f0f0ed` | `#161616` | 墨晕暗端（面板右下） |
| `--zmd-grain-tint` | `#808080` | `#808080` | 纸纹中灰（噪点以 SVG 自带 alpha 约 5% 叠在表面） |

- **墨晕**：`.zmd-wash` 用一条低对比径向渐变把面板从亮端过渡到暗端；渐变本身不承载文字，
  但文字**必须对两端都达标**（对比度门按 `wash-top` / `wash-bottom` 各量一次）。
- **纸纹**：`.zmd-grain::after` 平铺 120px 分形噪点（中灰、alpha 约 5%、`pointer-events:none`），
  亮暗两主题共用一张；它只做材质，不承载信息。只允许出现在有明确边界的浮层/页首带上，
  不铺全屏、不铺在文字上（文字在自己的层）。

### 2.3 强调与状态

| 角色 | 令牌 | 亮色 | 暗色 | 允许画字 |
|---|---|---|---|---|
| 强调（= 宿主信息蓝） | `--zmd-accent` | `var(--dsw-alias-state-business-primary)`（≈`#4176e6`，3.91:1） | ≈`#7aaaff`，7.48:1 | **否**（只做图形/焦点/选中条） |
| 强调上的墨 | `--zmd-on-accent` | `--zmd-panel` | `--zmd-panel` | 是（只压蓝底） |
| 焦点环 | `--zmd-focus` | 宿主蓝 | 宿主蓝 | — |
| 错误（4px 竖条 / 诊断左条） | `--zmd-danger` | `var(--dsw-alias-state-error-primary)` | 同 | 否（图形） |
| 在线 / 已验证 | `--zmd-online` | `#2f7d4f` | `#6bbf8a` | 是 |

**对比度实测（构建时由门逐条量）**：亮色正文 17.03:1 / 次级 7.97:1 / 弱墨 5.18:1（hover 底 4.67）；
暗色正文 15.38:1 / 次级 8.55:1 / 弱墨 5.08:1（hover 底 4.53）；控件边亮 3.43（沉底 3.30）/ 暗 4.69；
装饰细线 1.26–2.51:1（可见但不抢眼）。**强调蓝在亮色下只有 3.91:1，禁止作文字**；错误同样只作图形。

## 3. 字体

**内嵌 ZMD Archivo**（Archivo Variable, SIL OFL 1.1, wght 100–900 / wdth 62–125，
子集化为 46,728 B woff2，base64 data-URI，零网络请求），中文回落宿主字体栈：

```
font-family: "ZMD Archivo", var(--dsh-font-family-text, var(--dsh-font-family-text-default, …));
```

| 档 | 用途 | 规格 |
|---|---|---|
| 页首陈述 | 就绪句（live thing） | 20px / 28px / 500（不再是 600 大字） |
| 行题 | 名称、模型名 | 14px / 20px / 600 |
| 正文 | 值、动作词、答案词 | 13px / 20px / 400（宿主正文档） |
| 微字 | route id、标签、诊断、序号 | 12px / 18px / 400；序号 10px / 12px / 500、弱墨、`tabular-nums` |

不引入第五档；数字一律 `tabular-nums`。**不使用**大写字段码、`wdth` 125 显示字、`font-stretch` 变体。

## 4. 几何与材质

- **全直角**（圆只留给状态点）。
- **1px 细线是唯一的结构工具**：分栏、行间、面板边界、字段边。不用阴影、不用卡片投影。
- **负空间**：页首、卡片、井都靠上下留白分组；不加切角、不加装饰角标。
- **序号**：可数清单用两位数序号（rail 行、账本行、目录行），10px 弱墨、`tabular-nums`；
  其余位置不用序号。
- **禁止**：黄色、英文码、括号计数、大号显示数字、切角、扫光、扫描线、辉光、满屏噪点、
  假仪表盘、装饰性条纹。

## 5. 强调色语法（宿主蓝）

1. **蓝只出现在「你在这里 / 点这里」**：当前会话的 2px 左条、选中/选中的勾、焦点环、
   展开态的动作词 hover 下划线。
2. **蓝永不作文字**（亮色 3.91:1）；蓝底上的勾/字只用 `--zmd-on-accent`。
3. 其余一切都用墨色：选中填充 = `--zmd-panel-deep`，悬停 = `--zmd-hover`，
   当前行/分组用墨的粗细与线来分。
4. 错误红只做 4px 竖条与诊断左条；「缺密钥 / 不可用」的答案词仍是墨色（事实不靠染色喊叫）。

## 6. 组件语法（逐表面）

### 6.1 座位行（触发器 + 齿轮）

```
provider/model · effort  ⌄     ⚙
```

- 触发器：无左侧信号条；技术字形用 13px/400（宽度契约 `min(360px, 45cqw)` 不变）；
  悬停 = `--zmd-hover` 底；打开 = `--zmd-panel-deep` 底 + chevron 旋转；焦点环 2px 宿主蓝。
- 齿轮：直角图标按钮，1px `--zmd-line` 边；`data-edited` 时边取 `--zmd-accent`（图形，3.91:1 ≥3）。
- 不加任何黄色/字段码/序号。

### 6.2 模型卡

- **不再有顶部状态条**；卡面 = `.zmd-wash .zmd-grain` + 1px `--zmd-line-strong` 边，内容在自己的层。
- **两栏不变**（≤536px 折叠），模型窗格 331 / 名字列 175 / 徽章条 113 预算不变。
- **提供商栏**：行首两位数序号（10px 弱墨）；当前会话 = 2px 宿主蓝左条 + 名字 500；
  选中范围 = `--zmd-panel-deep` 填充 + `inset 1px --zmd-line-strong` 环（不占宽度）；
  悬停 = `--zmd-hover`。**不再有黄勾/信号条**。
- **搜索行**：无 `>` 提示符；底线输入（1px `--zmd-line-control`），聚焦底线变宿主蓝 + 2px 焦点环。
- **表头**：保留四个中文列名（文字输入 / 图片输入 / 支持推理 / 上下文窗口，功能解释，不换英文码），
  上下各一条 1px `--zmd-line`；右端**不加计数**。
- **模型行**：保留四列徽章与全部预算；行高 38px、行间 1px `--zmd-line`；
  悬停 = `--zmd-hover`；选中 = `--zmd-panel-deep` + 2px 宿主蓝左条 + 蓝底 `--zmd-on-accent` 勾；
  分组头改不透明 `--zmd-panel`（1px 下边），不加字段码/序号。
- **徽章图标**：单 16 网格、同一 stroke、14px 渲染（1.4px）；事实缺失留空；值用 tabular。

### 6.3 参数面板（齿轮）

- 头部：模型名（14/600）+ 「恢复默认」文字动作；**无 INSPECT/字段码**。
- 分区：中文标题（输入类型 / 上下文窗口 / 推理等级）+ 1px 细线；无英文码、无导向线端块。
- 开关：方形（开 = 宿主蓝底 + `--zmd-on-accent` 块；关 = 1px `--zmd-line-control` 框）。
- 输入：底线 1px，聚焦底变蓝 + 焦点环；错误红底线。
- 推理等级：行间 1px；选中 = `--zmd-panel-deep` + 2px 宿主蓝左条 + 蓝底勾。
- 不加关闭按钮（原面板没有，新增会改焦点链）。

### 6.4 模型配置页

- **页首**：只保留就绪陈述（20px，live thing，原有 key 重挂载不变）+ 一条 1px 细线；
  **无大序号、无字段码、无顶条**。
- **账本行**：48px；行首两位数序号（10px 弱墨）；行间 1px；状态竖条保留（4px，红/黄=error）；
  名称 14/600 + route id 12px；模型格文字动作；答案词右端（tabular）；门「管理」为文字动作，
  **去掉 ▪ 前缀**，hover 用宿主蓝下划线；展开行 = `--zmd-hover` 底。
- **设置井**：`--zmd-panel-deep` 填充 + 1px `--zmd-line`；标签列**回到单行中文**（凭据 / API 协议 /
  自动重试），表单控件 1px `--zmd-line-control`；危险动作前 1px 分隔线；诊断句红左条。
- **模型目录区**：`--zmd-wash` 面板 + 1px 边；头只写「模型目录」+ 状态 + 普通计数（不加 ROSTER 码）；
  模型行两位序号、id 13/600、容量事实右对齐 tabular、行间 1px；模型井内嵌 `--zmd-panel-deep`；
  `+ 添加模型` 为文字动作（无左条）；发现候选清单 = 方形勾选框（选中 = 宿主蓝底 + on-accent 勾）。
- **重试编辑器**：无 BACKOFF 码；两个数字框；摘要行用 18px 数字 + 微字；5 槽退避刻度条
  **改灰阶**（实心 `--zmd-ink-mute`、空槽 `--zmd-line`，`aria-hidden`，真实数据，reduced-motion 关闭）。
- **添加提供商**：页尾一条文字动作（去掉左条），hover 蓝下划线。

### 6.5 徽章与状态

- 四枚图标单 16 网格、14px；徽章只读、`aria-hidden`。
- 状态竖条：红=错误/缺密钥/不可用；不再有黄色状态条。

## 7. 动效

一条减速曲线 `cubic-bezier(0.2,0,0,1)`：悬停底色 120ms、按下 `translateY(1px)` 80ms、
选中勾 `scale(0.6→1)` 160ms、数值落定 `translateY(2px)` 160ms。
**无扫光、无揭幕、无透明度过渡**；`prefers-reduced-motion` 全关。

## 8. 响应式

断点语义不变：卡片 ≤536px 折叠；设置页 `@container` 560 / 484 / ≤360；≤484 隐藏次要列、
≤360 单列、40px 可点；106px 仍只保证「有序」（无横向溢出、无单字孤行、40px 目标）。
本轮新增装饰只有序号与墨晕，窄档无需为它们让位（序号在 ≤360 可隐藏）。

## 9. 必须保持的既有契约

- 交互与语义不变：座位 shadowing（priority -10）、单层模型卡、设置页唯一 modal、
  行内展开区、键盘链与 roving focus、ARIA、无第二弹层/无抽屉/无焦点陷阱。
- 宽度预算不变：卡片 331 / 175 / 113；页内容列 560 / 484 / 106。
- 质量门保留并逐条修订（见 `DESIGN.md` §5.38 的门表）：对比度 AA（两主题、含墨晕两端）、
  禁 opacity/filter/text-shadow/mix-blend、禁圆角、宽度预算、静态行为门、构建新鲜度、字体资产。

## 10. 质量门映射（本轮要改的门）

| 门 | 上一版（HUD） | 现行（墨色） |
|---|---|---|
| 令牌来源 | 字面量只许 `designSystem.ts` 令牌块 | 不变（令牌值已换成中性灰 + 宿主蓝引用） |
| 1px 预算 | 结构线 / 表单边 / 2–4px 信号条 | 结构线 / 表单边 / **2px 强调条（只许 `--zmd-accent`）** |
| clip-path / gradient | 允许 `.zmd-notch` 与点阵 | **删除 notch 与切角断言**；gradient 只许 `.zmd-wash`，stops 只用 wash 令牌 |
| 纹理 | 点阵 | 新增纸纹允许面：`.zmd-grain::after` 的唯一 data-URI 噪点规则；其余 background-image 仍禁 |
| 黄色规则 | 信号黄禁作字/边/细 mark、黄底配对 | **整套删除**（令牌层不再有 signal） |
| 字段码/大序号 | `FIELD_CODES` 白名单 + aria-hidden | **断言这些构件不存在**（无 `.zmd-code`、无 `.zmd-display`、无 FIELD_CODES 导入） |
| 强调 | accent 只做图形 | 不变：`--zmd-accent` 不得出现在 `color:`；蓝底必须 `--zmd-on-accent` |
| 对比度 | 注册全部 HUD 画字 | 注册剩余画字；墨晕两端各量一次；装饰线亮度区间保留 |
| 字体资产 / build-fresh | 已建立 | 不变 |
| mutation | 旧 22 + HUD 17 条 | 旧 22 保留；HUD 17 条里 8 条改写成墨色规则，其余删除（保留证明不重复） |

## 11. 有意不做的事

1. **不做 HUD**：不要字段码、大号显示数字、切角、扫光、扫描线、括号计数、假仪表盘。
2. **不用黄色**：强调只用宿主蓝；错误只用红竖条；绿只做在线态。
3. **不把宿主整体换主题**：只重制本插件表面。
4. **不在装饰里造假数据**：退避刻度、序号计数全部来自真实数据。
5. **不改交互形态**：不新增弹层、不搬运控件、不改键盘链与宽度预算。
6. **不做全屏噪点/纸张纹理铺满**：墨晕与纸纹只在有边界的表面上，文字永远可读。
