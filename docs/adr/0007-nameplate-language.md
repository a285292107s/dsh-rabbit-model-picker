# ADR 0007 — v2「铭牌」：用构图换代，不换语法

- 状态：已采纳（2026-10-18）
- 取代：ADR 0005 / 0006（墨色语言 v1.0 / v1.1，均已于 2026-10-17 删除，见 git 历史）
- 相关：`DESIGN.md` §5.42 是实现契约与实测记录

## 背景

墨色语言（v1.x）在同日交付后，由一位独立评审按 Awwwards 口径打分：设计 6.0 / 可用性 6.0 /
创意 6.5 / 内容 6.0，加权 **6.1**（证据：`.taste-skill/v2-audit/baseline-critique.md`）。
结论不是"颜色不对"，而是**没有构图**：

1. 设置页是数据结构的忠实渲染（11 行同高同权、三个无表头的右对齐列）；
2. 材质只是一条 100px 的页首带（页面主体实测 sd 0.0、range 0.0 —— 数学上纯平）；
3. 动作没有语法（"可用""管理""删除""保存"全是 14px/500 同一种样子，没有危险语域）；
4. 模型卡右栏以空白收尾（最后一条分隔线在 642px 中的 433px 处）；
5. 字阶倒置（24px 给了每次加载都会变的计数句，页面标题根本没渲染）；
6. 1px 细线只有 1.38:1 / 1.32:1 —— 整套语言的看家手势在阈值之下看不见。

## 决定

**方向不换，换构图。** 单色墨阶、宿主蓝、"全直角 + 1px 线"、五档字阶、内嵌 Archivo 保留；
在此基础上引入四条可被截图证伪的规则：

| # | 规则 | 为什么 |
|---|---|---|
| 1 | **每个表面有顶也有底**：以自身名字（24px）开场，以一条脚注收尾（1px 线 + 12px 一行） | 空白收尾读作"没做完"；脚注把 void 变成结构。模型卡、页面、目录区三处同一手法 |
| 2 | **边距列承载记录**：26px 序号列（≤106px 收 16px），提供商栏的 `01`–`09` 是真快捷键 | v1.1 的序号是**装饰冒充快捷键**：没有任何数字键处理器。半套系统比没有更糟 |
| 3 | **线标记录、色阶标选择**：账本行与分栏用 1px 线，密集的模型列表**不画**逐行细线；状态是状态列里的一个词 + 6px 方块，不是行首一条 4px 红边 | 三条竞态的"边语言"（线 / 填充 / 彩条）让每个边界都要重新解释；红边离"缺密钥"三个字太远，读起来像滚动条 |
| 4 | **动作四档**：墨印（每表面一个真写操作）/ 描边门（一行唯一入口）/ 文字（可逆）/ 危险（次级墨，hover 转红，永不填充） | 一个界面里"删除提供商"和"可用"长得一样，是可用性缺陷而不是风格问题 |

同时修掉两处事实性缺陷：细线提到可见区间（弱线 1.85–2.17:1、框架线 3.05–3.28:1、控件底边
4.17–4.83:1）；材质改为**整块表面**（`.zmd-plate`）+ **每主题一张噪点令牌**（`--zmd-grain-tile`），
因为单张 8% 灰在亮底量到 3.1/255、暗底 9.2/255 —— 那是两种材质，不是一种材质的两套主题。

## 取舍（明确放弃的东西）

- **不加新色**：仍是灰/黑 + 宿主蓝。蓝从"选中 + 开 + 焦点"收缩到只表示"你在这里"
  （选中、当前、焦点），开关的"开"改成墨 —— 一个颜色两个意思会互相消解。
- **不加圆角、阴影、渐变当深度**：几何是 v1 里唯一被评审表扬的一半（keeper K2），不动。
- **不做入场编排**：会变的句子不再有动画；最大字号只留给稳定的东西。工具表面保持安静。
- **不引第二字体**：中文仍回落宿主栈；再引一个字体会改语气并加包体，证据不足。
- **不把 106px 当成"能排下就行"**：宿主真机内容列约 106px，v1.1 是把 ≤360 的网格拉长
  （协议下拉截断成 `Ope`、删除动作折三行）。v2 为它单独开 ≤240px 的单列分支。

## 后果

- 行高与页面总高继续上升（账本行 48px 不变，但井/目录区多了井头与字段行间距）；换来可扫读的层级。
- 模型卡多了一条 32px 的牌头与一条 36px 的脚注，可视行数进一步减少（滚动增加）。
- 新增两处文案键（`config.listheadState` / `config.listheadAction`、`card.*`），中英同键同序。
- **静态验收的缺口不变**：键盘链、滚动、焦点陷阱、Esc 分层只能在真机验证。
