# 0002. 分阶段：先以新 id 并存对照，功能对等后再遮蔽官方「模型」页

> ⚠️ **本决策已被 [0003](./0003-parallel-tab-with-full-parity.md) 取代。**
> 用户改为「一次性做完，不拆阶段」，并在落地形态上选择**不遮蔽**官方页——
> 因此本文的「阶段划分」与「终局遮蔽 `models`」两个前提同时不成立。
> 0001 → 0002 → 0003 的完整改口链条保留在此，不回溯修改。

## 状态

`superseded by 0003`

## 背景

ADR 0001 记录的决定是「新增平行 tab，官方页保留为**全功能兜底**，本插件**不复刻**官方语义层」。

追问第 5 轮中，用户澄清了真实意图：**最终目标是取代官方模型页**，开发初期保留它只是为了**方便对照**。

两者并非完全冲突——「现在并存」仍然成立——但 ADR 0001 把「并存」写成了**长期承诺**，
并据此正当地放弃了功能对等。这与「终局取代」的目标相反。若不更正，
后来者会读到一份指向相反方向的决定，并据此拒绝所有补齐官方能力的请求。

## 决策

采用**分阶段**路线：

1. **当前阶段**：本插件以**新 id**（「模型配置」）注册 `settings.section`，与官方 `id: 'models'` **并存**。
   官方页保持原样，作为对照与兜底。此阶段**不遮蔽**、不抢占 `models` 这个 cell。
2. **终局阶段**：当本页与官方页**功能对等到可以取代**时，改为**遮蔽** `settings.section` 的 `id: 'models'`
   （`priority` 低于官方那一笔），使官方页不再渲染。

遮蔽机制不必新造：它与本插件在 composer 上遮蔽 `conversation.input.model` 座位（`priority: -10`）
是同一套 `list` slot 语义，删除本插件的行即可完全还原。

## 后果

**正面**

- 开发期始终有一份可运行的官方实现可对照，减少「靠猜官方的语义」的成本。
- 终局方案不依赖任何未验证的机制——遮蔽是本插件已经在用的 slot 语义。
- 阶段切换是**局部改动**（加一个 `priority`、把 id 对齐），不必重写页面。

**负面**

- **功能对等是一笔迟早要付的账**，且它比页面本身大：首启姿态、删除的两步语义、
  乐观并发的冲突文案、模型目录编辑、中英双语、五个推送失效事件的订阅——
  ADR 0001 正是以「不复刻」省掉了这些，本文把这份节省**重新记为负债**。
- 在遮蔽之前，两页会出现**状态一致但能力不一致**：同一份设置文档，
  一个页面能改的东西另一个不能。用户可能在一个页面找不到另一个页面有的功能。
- 终局遮蔽一旦发布就是对既有用户的行为变更，需要一次明确的迁移说明，不能静默升级——
  官方页会消失，而用户并没有点过「同意」。

**中性**

- 遮蔽的**时机**不由本文决定，而由「功能对等清单」是否清空决定；该清单尚未建立（见下）。

## 替代方案

| 方案 | 为何未采用 |
|---|---|
| 维持 ADR 0001：永久并存 + 永不对等 | 与用户明确的终局目标相反；把「省成本」当成了目标本身 |
| 现在就遮蔽 `models`（一步到位） | 开发期将失去官方页对照，与用户「保留官方页方便对照」的要求直接冲突 |
| 不遮蔽，仅靠「用户不再需要官方页」实现事实取代 | 设置里会永久存在两个模型页，官方页仍可能被误点，取代不彻底 |
