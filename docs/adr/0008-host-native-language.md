# ADR 0008 — v3「宿主原生」：把插件的视觉语言换成宿主的

- 状态：已采纳（2026-10-18）
- 取代：ADR 0007（v2「铭牌」）
- 相关：实现契约在 `src/client/designSystem.ts` 的 `--zmd-*` 映射块、`CONTEXT.md` 的视觉语法一节

## 背景

v2「铭牌」交付后，按 Awwwards 口径复核，暴露的不是配色问题，而是**两套视觉语言并置**：

1. 插件的面板铺了一层自己的材质（`zmd-plate` 径向渐变 + `zmd-grain` 噪点），而宿主的面板底本来
   就是 `--dsw-alias-settings-card-fill` + 0.5px 边；两层叠在一起，插件那一块明显比周围「脏」。
2. 插件的线是 1px，宿主是 0.5px。相邻一读，插件的线不是「更清楚」，而是「更粗」。
3. 插件自造了宿主没有的语法：26px 边距列 + `01` 序号（而只有提供商栏的数字键是真快捷键）、
   目录式标题尾线、24px 陈述档、底线字段、四档以外的动作形态。
4. 内嵌 Archivo 让插件的中文与拉丁文都落在宿主字体栈之外，一页里出现两种字重节奏。
5. 账本行每行一张卡（`border-radius` 20 + 四条 0.5px 边），11 行就是 11 个边界；宿主的
   General 页是**一张列表 + 行间线**。

也就是说：v2 让插件「有构图」，代价是它不再像宿主的一部分。

## 决定

**语法换代，不是重排构图。** 插件的每个表面改用宿主设置页的语法，自己只保留宿主没有的那件
东西——**账本行的三格事实 + 一个门**。

| # | 规则 | 为什么 |
|---|---|---|
| 1 | 令牌层只做映射：`--zmd-*` 全部指向 `--dsw-*`，不造颜色、不造字体、不造半径 | 宿主换主题时插件自动跟随，不用维护两套色板 |
| 2 | 边一律 0.5px，半径取宿主 `--dsw-radius-*` 档（4/8/12/16/20/28） | 与宿主同一把尺子；这是「像不像宿主」最显眼的一处 |
| 3 | 字阶换成宿主档：11/12/13/14/16；24px 陈述退休 | 24px 在宿主的设置页里没有对位元素，读起来像自建页面 |
| 4 | 动作四档照抄宿主：主按钮 36/12px、描边 36/0.5px、文字 28、危险 28 红字 | 宿主已经有一套被验证过的层级；自造一套只会让「删除」和「可用」长得一样（v2 的问题） |
| 5 | 账本合并成一张卡 + 行间 0.5px 线 | 宿主 General 页的 row list 就是这个形态；11 行 11 个边框是视觉噪声 |
| 6 | 删内嵌字体，`--zmd-font` = `--dsw-font-family` | 一页两种字重节奏；且 `fontAsset.ts` 让包里多了 63KB 与一个需要 Python 的构建步骤 |
| 7 | 状态用宿主 `StateDot` 语义：8px 圆点（绿/红/灰）+ 词 | v2 的 6px 方块离「缺密钥」三个字太远，读起来像滚动条的残片 |

## 取舍（明确放弃的东西）

- **放弃 v2 的材质**：纸纹与墨晕整套删除。插件不再有自己的「纸」，它就是宿主的一块面板。
- **放弃序号与边距列**：`01`–`09` 从提供商栏、账本行、模型行三处删除。数字键跳行仍然可用，
  但不再画序号——画了就是装饰冒充快捷键。
- **放弃 24px 陈述档**：页名降到宿主的 16/24/500。
- **放弃底线字段**：所有输入/下拉改成四边 0.5px 的宿主形态；底线在圆角输入框旁边读成「残缺控件」。
- **放弃内嵌字体**：`fontAsset.ts`、`scripts/build-font-asset.mjs`、`docs/fonts/Archivo-OFL.txt`
  一并删除，`package.json` 的 `font:build` 与 `files` 条目同步去掉。包体从 383,896 B 降到
  298,472 B（`lib/client.js`）。
- **不放弃的**：结构（事实在行上、控制在井里）、强调蓝只表示「你在这里」、危险动作永不填充、
  `zmd-` / `dmc-` / `dmp-` 三个类名域、容器查询的四个断点。

## 后果

- 插件在亮/暗两种主题下与宿主同色、同线、同圆角、同字阶；宿主换主题时插件不需要改。
- 少了 63KB 与一个构建步骤；`npm run font:build` 这个入口不存在了。
- 「模型配置」页从 11 行同高同权的行列表，变成**一张卡 + 统一的 52px 行**；行内展开的井与目录区
  用宿主 `--zmd-nested` 的底表达归属，不再画竖线。
- 新增两个文案键（`badge.head.*` 列头，取代原来的图例 `badge.key.*`），中英同键同序。
- **静态验收的缺口不变**：滚动、焦点链、Esc 分层、宿主窄窗口下的真实列宽（106px）仍只能在真机验。
